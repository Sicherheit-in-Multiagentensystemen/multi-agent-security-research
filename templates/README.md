# 可复用文本模板

| 模板 | 使用时机 |
| --- | --- |
| [PAPER_NOTE.md](PAPER_NOTE.md) | 阅读单篇论文、提取证据与待验证问题 |
| [THREAT_MODEL.md](THREAT_MODEL.md) | 确定具体系统的信任与授权边界 |
| [EXPERIMENT.md](EXPERIMENT.md) | 预先定义实验并记录可复现结果 |
| [COLLUSION_AUDIT.md](COLLUSION_AUDIT.md) | 用 Colosseum 思路登记通信、行动与联盟收益的联合审计 |
| [WEEKLY_REVIEW.md](WEEKLY_REVIEW.md) | 汇总本周期阅读、判断与下一步 |
| [SURVEY_OUTLINE.md](SURVEY_OUTLINE.md) | 将文献矩阵组织成课题综述 |

复制模板后填写；占位内容不算已完成研究。保存的阅读深度与实验状态必须与实际工作一致。
