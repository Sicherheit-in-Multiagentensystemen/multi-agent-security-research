# 研究路线与候选问题

以下是待验证的研究计划，不是已证明的领域空白。选题前应补做针对性检索。

## 候选研究问题

| 编号 | 问题与假设 | 最小实验 | 判定依据 |
| --- | --- | --- | --- |
| RQ1 | 跨代理保留数据来源，是否比仅在单代理内隔离更有效？ | planner + 两个 worker；只允许污染一个工具输出；比较无防御、单代理隔离、跨代理来源保留 | 未授权实际动作、正常任务完成率、权限日志 |
| RQ2 | 固定攻击和 token 预算后，拓扑是否改变传播范围？ | 同一任务与角色，比较层级、环形、全连接；固定初始失陷节点 | 传播比例、链路深度、任务效用与费用 |
| RQ3 | 共享记忆是否引入跨任务持久化风险？ | 私有/共享记忆；有/无写入审核；污染后切换到新任务 | 新任务失陷、污染可撤销性与误拦截 |
| RQ4 | 可用性攻击是否能绕过只看内容危害的防御？ | 模拟无害文本引起的递归委派/等待；比较预算、深度、时限和循环检查 | 预算耗尽率、延迟、合法长任务完成率 |
| RQ5 | 安全结果是否受工具名称的表面线索影响？ | 保持操作语义不变，只更换命名或描述格式 | ASR 变化、正常效用变化、统计不确定性 |
| RQ6 | 对话层串谋评分能否预测实际联盟优势？ | 依照 Colosseum 比较公共通道、良性私有通道和目标干预；增加预算匹配对照 | 配对公共目标差值、两组 regret、联盟优势与 judge 分歧 |

RQ1 参考 P07/P16；RQ2 参考 P03/P06/P11；RQ3 由 P15 的记忆攻击延伸；RQ4 参考 P04；RQ5 参考 P18；RQ6 参考 P25 及[Colosseum 审计框架](../frameworks/COLOSSEUM_AUDIT.md)。延伸问题未被本仓库独立验证。

## 建议的首轮里程碑

1. **范围冻结**：选择一个 RQ，写明系统、攻击者和授权边界；完成一页威胁模型。
2. **文献精读**：精读 5–8 篇直接相关论文，填补证据矩阵的假设与定位字段。
3. **基线建立**：选定一个现成基准版本，先确认无攻击时的正常任务能力。
4. **最小比较**：增加双/多代理边界，在相同任务和预算下比较四种攻击/防御条件。
5. **误差分析**：区分推理失败、权限拒绝、网络错误、越权成功与资源耗尽。
6. **形成产出**：提交可复查配置、结果表、失效案例和一份短报告，再决定扩大规模。
